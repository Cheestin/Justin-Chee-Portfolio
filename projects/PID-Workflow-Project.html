Simulated and Designed a PID Workflow for a Quadcopter

Quadcopters are widely used in commercial drones for functions like aerial photography and delivery. A core aspect of the design of these drones is attitude stabilization, which is commonly addressed through a PID feedback loop in the flight controller. This study presents the design and validation of a PID based flight controller for a quadcopter, developed in a MATLAB/Simulink simulation. A nonlinear dynamic model was derived from first-principles Newton-Euler equations and used as a plant for PID controllers for pitch, roll and yaw. The PID controllers were tuned using the Simulink PID Tuner, before being manually adjusted further to reduce the oscillations created by aggressive controller gains. This was then validated through step response, disturbance rejection and parameter uncertainty testing.
